# Latvietes ASV smiltīs

Neoficiāla fanu lapa par Latvijas pludmales volejbolistēm ASV universitātēs: https://asvsmiltis.com

- `index.html` — lapa (nemainās ikdienā)
- `data.json` — dati; tos katru rītu atjaunina ieplānots Claude uzdevums
- `photos/` — spēlētāju bildes ar avotu norādi `data.json` laukā `photoCredit`
